# Upgrade-ready marker source

`FarmHandUpgradeReady.png` is the reusable visual shown behind a defender that is waiting for a
weapon upgrade choice. It is assigned by `TAD > Defenders > Rebuild Farmhand Visuals` and retains a
procedural fallback for legacy test prefabs.

Prompt summary: a small red low-poly upward arrow with a golden starburst, top-down/three-quarter,
transparent background, readable at mobile size, with no text, UI panel, logos, or watermark.

Generated with Codex built-in ImageGen on 2026-10-12. The runtime applies the existing transparent
red presentation tint so the marker stays visually consistent with TAD's red upgrade-ready rule.
